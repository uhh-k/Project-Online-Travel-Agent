# Project Online Travel Agent

The current project aims to develop a data warehouse (DWH) for an online travel agent. 

The online travel agent "GlobeTrotter Hub" provides a digital platform that allows consumers to search, 
compare, and book travel-related services such as flights and hotels. The agent plans now to develop a data warehouse for storing and analyzing the booking data to make data-based business decisions. It is essential to retain historical data to strengthen the analytical capabilities. The data to be stored includes information about aircraft, airlines, airports, customers, hotels, and bookings for both flights and accommodations. The data warehouse will be utilized by data analysts and data scientists to conduct analyses aligned with business objectives. They will be able to perform complex SQL queries to extract insights. The focus of analysis will likely be on identifying trends related to flights, hotels, and customer behaviors. Some potential analytical requirements include: 

- Tracking Daily Booking Volumes: Track the number of bookings for flights and hotels each day. 
- Monitoring Average Ticket Prices over Time: Monitor fluctuations in ticket prices to detect demand changes and guide pricing strategies.

The project is based on the a [website](https://istywhyerlina.medium.com/designing-simple-data-warehouse-model-for-online-travel-agent-ota-with-dbt-ab4985f8e7da) (State: October 17, 2025) that demonstrates designing DWH for an online travel agent. It is also the source of the raw data. Necessary modifications were made to fit in the implementations.
